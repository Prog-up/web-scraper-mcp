# Release 1.1.1

This patch release includes the tool reliability improvements and public
repository preparation merged in PR #9. All ten MCP tools remain available.

## Changes

- Fetch crawl pages in bounded parallel batches (three workers by default),
  sharing capacity across jobs and retaining cancellation and result limits.
- Deduplicate redirected pages before charging their result byte budget.
- Remove navigation and outer page chrome from short-page content while
  preserving product listings and article headers.
- Use Ollama JSON Schema output mode for structured extraction, with local
  validation and bounded model inputs.
- Give research models explicit source numbers and reject invalid citations
  and literal placeholders. Citation checks do not establish factual accuracy.
- Add reproducible tool benchmarks and regression coverage; improve public
  setup, deployment, security, contribution and release documentation.
- Restrict package/container build inputs, include license metadata, and
  correct the internal package version.

## Upgrade

Use `progup/web-scraper-mcp:1.1.1` once the release workflow has successfully
published and verified its digest. The historical `latest` tag is immutable.
Existing authentication, browser sandbox, guarded egress and resource limits
remain required; see [deployment](../deployment.md).

`SCRAPER_CRAWL_CONCURRENCY` defaults to 3 and supports values from 1 to 8,
subject to shared fetch capacity. Set it to 1 for sequential crawling.
There are no tool renames or required client configuration changes.

## Validation and publication

The release workflow must pass the Python 3.11–3.13 matrix, dependency and
secret checks, sandboxed browser regressions, and the exact-image vulnerability
gate before pushing. It then signs, attests and verifies the published digest.
This release has its own explicitly approved, expiring vulnerability inventory,
described below.

## Approved security exception

The fresh local candidate scan reports the same 59 HIGH and one CRITICAL
unfixed Debian package findings as 1.1.0 (22 distinct CVEs; no additional or
fixable findings). The CRITICAL finding is CVE-2026-6653 in libxml2.
On 8 October 2026, the user explicitly approved publication with this exact
inventory after checking supported updates and package removal. Removing
libxml2 also removes libgbm, which Chromium requires; other affected libraries
are required by Chromium and Debian core packages. This does not establish
that the vulnerabilities are harmless or that other base-image designs cannot
avoid them.

The [1.1.1 exception](../../deploy/release-exceptions/1.1.1.json) is owned by
Prog-up and expires on **13 October 2026 at 23:59:59 UTC**, without extending
the existing expiry. Fixable or additional HIGH/CRITICAL findings remain
blocked. This is acceptance of known vulnerabilities, not a clean scan.
See [candidate evidence](1.1.1-evidence.json) for the exact inventory, image ID,
database timestamp, removal checks and local validation results.

Local validation passed 162 tests on Python 3.13, lint, formatting, typing,
Bandit, and the dependency audit (130 packages; zero affected). Both sandboxed
browser regression suites passed against the fresh candidate image.

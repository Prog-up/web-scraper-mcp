# Release 1.1.0

This release contains the repository security remediation and restores all ten
advertised MCP tools. Python 3.11–3.13 is supported.

## Changes

- Restore crawl, status/cancellation, map and persistent browser actions on the
  hardened shared fetch/browser layer, with bounded jobs/sessions and cleanup.
- Validate destination addresses when connecting; pin approved public IPs while
  preserving Host, TLS SNI and certificate validation. Reapply policies on redirects.
- Enable sandboxed Chromium behind guarded egress and isolate browser sessions.
- Require bearer authentication for HTTP; preserve token-free stdio.
- Enforce response/input/model/concurrency/cache budgets and validated schemas.
- Refresh Python and Debian dependencies: PyJWT 2.15.1, AnyIO 4.15.1, Playwright
  1.63.0, and perl-base 5.40.1-6+deb13u1 in the tested Debian 13 image.
- Exercise all ten tools, real stdio/HTTP MCP transports and sandboxed Chromium.
  The prior feature validation passed 136 tests on Python 3.11, 3.12 and 3.13.
- Publish only through GitHub Actions after source checks, exact-image tests and
  vulnerability scans; sign and attest the published digest with an SPDX SBOM.

## Upgrade

HTTP deployments must set `SCRAPER_AUTH_TOKEN` and provide a Bearer header.
Browser rendering/session tools require `SCRAPER_BROWSER_ENABLED=true` and the
isolated guarded-proxy topology described in README. Plain scraping is static
by default. Explicit browser actions may submit same-origin forms; background
and cross-origin writes, WebSockets, service workers and downloads are blocked.
Configure an installed model and reachable trusted Ollama endpoint. Ollama
thinking defaults to false and can be configured explicitly.

Docker Hub tags are immutable. The release will use `1.1.0` and a full commit tag;
the historical `latest` tag cannot be replaced. Use the version tag or verified
digest when upgrading.

## Approved security exception

On 6 October 2026, the user explicitly approved release 1.1.0 with 59 HIGH and
one CRITICAL unfixed Debian package findings covering 22 CVEs. The CRITICAL
finding is CVE-2026-6653 in libxml2. This is acceptance of known vulnerabilities,
not a clean full scan or a claim that these CVEs do not apply.

The [machine-readable inventory](../../deploy/release-exceptions/1.1.0.json)
is owned by Prog-up and expires at 23:59:59 UTC on 13 October 2026. The release
and PR gates accept only those exact Debian package names, installed versions,
CVE IDs and severities, and only while no fixed version is available. Additional
or fixable HIGH/CRITICAL findings, a different release, invalid policy/report
inputs, or an expired exception block publication. Complete Trivy reports are
retained for 90 days. Subsequent releases retain the strict gate.

GitHub Actions builds and tests the image before pushing, then signs, attests
and verifies its digest. Publication status and the resulting digest are recorded
in the GitHub release and workflow run.
